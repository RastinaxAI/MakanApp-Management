# فایل‌های نگه‌داری

`history` سوابق غیر اجرایی و نسخه‌های قدیمی است. انتقال‌ها در `history/ORGANIZATION-MANIFEST.json` ثبت شده‌اند. `generated` خروجی‌های موقت و گزارش آزمون است و وارد Git، Docker یا بسته سرور نمی‌شود.

فایل‌های خصوصی env و نشست‌های فعال جابه‌جا نشده‌اند. برای استقرار فقط بسته پوشه `release` را ارسال کنید.
