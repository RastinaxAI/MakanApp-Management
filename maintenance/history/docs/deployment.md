# استقرار کلاینت ماکان (سابقه)

این برنامه برای فرد عادی، دانشجو، استاد، والدین و مدیر آموزشگاه است. صفحه، نشست یا API واسط مالک پلتفرم در این کلاینت وجود ندارد.

- مسیر ورود: /enter؛ مقصد اصلی: /personal/education.
- Browser → Next.js: برای انتشار HTTPS و COOKIE_SECURE=true؛ APP_ORIGIN مطابق origin قطعی باشد.
- Next.js → Backend: BACKEND_BASE_URL محیط صحیح؛ launcher محلی QA عمداً8090 است. خطای سرور موجب انتقال خودکار به محیط دیگر نمی‌شود.
- کلید خصوصی SESSION_SECRET باید64 رقم hex تصادفی باشد؛ فایل env موجود را بازنویسی نکنید.
- توکن فقط در نشست رمزگذاری‌شدهٔ سرور است؛ مرورگر فقط cookie تصادفی HttpOnly و SameSite=Strict می‌گیرد.
- این نسخه برای یک process سرور و پوشهٔ پایدار نشست طراحی شده است؛ چند replica بدون session store مشترک پشتیبانی‌شده معرفی نشود.
- فضای شخصی بدون سازمان معتبر است؛ نقش فعال، membership و زمینه از بک‌اند می‌آیند. هیچ نقش تازه‌ای از شماره یا UI ساخته نمی‌شود.
- APIهای فعال فقط /api/client هستند و surface محدود دارند؛ مجوز نهایی هر منبع در بک‌اند بررسی می‌شود.
- Auth، فایل و SignalR واسط اختصاصی دارند؛ فایل خصوصی و پاسخ دارای نشست cache عمومی نمی‌شود.
- شناسه‌های نسخه و revision مات‌اند؛ تغییر حساب/زمینه درخواست دیررس و cache قبلی را بی‌اعتبار می‌کند.
- مجوز سخت‌افزار دوربین فقط برای مسیر چت تعریف شده؛ امنیت فایل و پرداخت با کنترل فرانت‌اند جایگزین نمی‌شود.

راهنمای اجرای Docker در [docker.md](docker.md) و وضعیت پذیرش واقعی در [PROGRESS.md](PROGRESS.md) است.
