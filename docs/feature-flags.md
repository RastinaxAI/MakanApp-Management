# وضعیت قابلیت‌ها

مرجع مرکزی: `src/lib/flags.ts`. این محدودیت‌ها از سند تحویل Release گرفته شده‌اند و مشاهده route در Swagger آن‌ها را فعال نمی‌کند.

| کلید             | مقدار | دلیل                                             |
| ---------------- | ----- | ------------------------------------------------ |
| aiCopilot        | false | provider مسدود؛ موفقیت واقعی تأیید نشده          |
| productionRag    | false | lifecycle عمومی RAG خارج از Release              |
| realCheckout     | false | فقط foundation پرداخت؛ checkout واقعی تأیید نشده |
| realPushAccepted | false | پذیرش محیط و دستگاه Web Push/FCM باز است         |
| voiceVideoLive   | false | P3 فاقد Runtime منتشرشده                         |

رابط مدیریتی پلن، اشتراک، سفارش و سلامت مستقل از پذیرش واقعی provider است. هیچ دکمه پرداخت، تماس یا Copilot به پنل اضافه نشده است.

در ۳ آبان ۱۴۰۵ رابط نصب PWA، ثبت/لغو دستگاه Web Push و صندوق اعلان شخصی به API موجود متصل شدند. `realPushAccepted` تأیید تحویل واقعی از provider است و تا آزمون روی محیط و دستگاه واقعی false باقی می‌ماند. ثبت موفق در آزمون مستقل یا نمایش اعلان محلی، پذیرش تحویل واقعی محسوب نمی‌شود. [گزارش نصب و اعلان‌ها](pwa-release.md).

حالت نمایشی داخلی، داده‌های آن و مسیرهای `/demo/*` در ۲۵ اکتبر ۲۰۲۶ حذف شدند. پرچمی برای فعال‌کردن دوباره این مسیرها وجود ندارد. همه صفحات پنل به ورود مالک و پاسخ سرور پیکربندی‌شده وابسته‌اند.
