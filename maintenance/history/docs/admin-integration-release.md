# تطبیق پنل ادمین با راهنمای اتصال بک‌اند

تاریخ: ۷ آبان ۱۴۰۵، ۲۹ اکتبر ۲۰۲۶. مرجع: راهنمای AdminPanel Backend Integration انتشار 20261028-final-6f274767 و OpenAPI واقعی محیط تست در همین روز.

نسخه فعال فقط Platform Admin است. کلاینت شخصی/آموزشی قبلی در archive/client-before-admin-20261029 حفظ شد. مسیرهای /personal، /enter، /organization و صفحات لندینگ در نسخه فعال وجود ندارند. MakanWebsite دست‌نخورده باقی ماند.

ورود OTP، gate سمت سرور، نقش دقیق PlatformOwner و platform.access، بررسی مستقل مجوزها برای هر عملیات و بازبینی هویت در درخواست‌ها برقرار است. مدیر مدرسه و مالک یک گفت‌وگو مالک پلتفرم فرض نمی‌شوند. مجوزهای نامشخص fail-closed هستند و از نام نقش مجوز ساخته نمی‌شود.

تمام ۵۱ مسیر ادمین در OpenAPI زنده با snapshot پنل آرشیوی یکسان بودند. SDK و واسط اجرا به ۷۲ عملیات ادمین و حساب لازم محدود شدند؛ API مدیریت مدرسه و پیام‌های شخصی از allowlist حذف شدند. اتصال پروفایل شخصی اپراتور به معنی بازکردن کلاینت شخصی نیست. دریافت workspace مدرسه هنگام ورود حذف شد.

فرم‌ها و enumها، Required/Nullable، فیلتر و صفحه‌بندی، نسخه و reason از قرارداد تولید می‌شوند. تعلیق سازمان پیش‌نمایش اثر دارد؛ بستن عضویت حذف حساب نیست. پلن‌ها نسخه‌بندی و انتشار مستقل دارند. آموزش و سفارش مالی فقط‌خواندنی‌اند. داده پیام‌رسان فقط metadata است؛ expanded-context فقط در رسیدگی و با مجوز مربوط نمایش داده می‌شود.

MFA، AI Runtime، مدیریت provider و کلید AI، quota نامشخص و toggleهای قراردادنشدهٔ audience/visibility به پنل اضافه نشده‌اند. قابلیت‌های بعدی School Backend مبنای این تحویل نیستند. خطاهای correlationId نیز به کد پیگیری قابل نمایش تبدیل می‌شوند؛ اطلاعات حساس خطا نمایش یا log نمی‌شود. 403 refresh ندارد و mutation خودکار تکرار نمی‌شود.

نسخه شخصی، تنظیمات runtime و مسیرهای مدرسه با پنل ادمین ادغام نشده‌اند. envها و نشست‌های واقعی هنگام بازیابی سورس تغییر نکردند. نتایج آزمون نهایی در admin-integration-verification.json ثبت می‌شوند.

## نتیجه بررسی نهایی

۱۱۱ آزمون واحد، ۲۰ سناریوی مرورگری ادمین و هر ۶ آزمون Docker موفق شدند. TypeScript، ساخت production و ساخت image نیز موفق بودند. ورود واقعی حساب مجاز 09120000105 با OTP تست به نشست مالک رسید؛ هویت PlatformOwner و platform.access تأیید و اطلاعات سازمان، کاربران و سلامت از سرور واقعی با پاسخ ۲۰۰ دریافت شد. نشست مستقل آزمون در پایان با پاسخ ۲۰۴ بسته شد. مسیرهای شخصی، مدرسه و لندینگ و API قدیمی MFA در نسخه نهایی ۴۰۴ بودند. آزمون عملیات تغییر دادهٔ تجاری روی بک‌اند مستقل آزمون انجام شد؛ عملیات تجاری واقعی روی سرور تست ایجاد نشد.
