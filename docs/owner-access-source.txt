12 .  Frontend Guard Pattern
1) Authenticate user normally
2) GET /api/admin/v1/me
3) if 401/403 -> no Platform shell
4) if 200 -> cache safe roles/permissions in application state
5) gate each menu/action by required permission
6) still handle 403 from every API as authoritative
7) never infer school-role access from Platform role
